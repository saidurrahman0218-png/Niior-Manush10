# নিজর মানুষ — হোম ডেলিভারি সার্ভিস, বিশ্বনাথ
## Production Deployment & Integration Guide

### ১. সিস্টেম পরিচিতি (System Architecture)
- **ফ্রন্টএন্ড**: React 19 + TypeScript + Vite + Tailwind CSS
- **ম্যাপ ও লাইভ ট্র্যাকিং**: Leaflet OpenStreetMap (বিশ্বনাথের ৮টি ইউনিয়ন কাভারেজ)
- **ব্যাকএন্ড**: Node.js + Express (পূর্ণাঙ্গ রেস্টফুল এপিআই)
- **পারসিসটেন্স ডেটাবেস**: `data/db.json` (স্বয়ংক্রিয় ফাইল সিঙ্ক্রোনাইজেশন) + Firebase Firestore সিঙ্ক
- **ডিজিটাল মেমো ও ভাউচার**: প্রিন্ট অপ্টিমাইজড গ্রাহক ক্যাশ মেমো এবং পার্টনার শপ প্রকিউরমেন্ট ভাউচার (PDF/Print সাপোর্ট)

---

### ২. মডিউল ডিরেক্টরি পরিচিতি (Module Breakdown)
1. **`AdvancedAccountingLedger.tsx`**:
   - আজ, গতকাল, ৭ দিন, চলতি মাস ও কাস্টম ডেট রেঞ্জ ফিল্টারিং।
   - COD রিকনসিলিয়েশন ও রাইডার ক্যাশ-ইন-হ্যান্ড ট্র্যাকিং (৳৫,০০০ লিমিট অটো-ব্লক)।
   - কোম্পানির মোট আয় (সার্ভিস চার্জ + ১০% ডেলিভারি কমিশন) ও নীট লাভ হিসাব।
   - এক্সেল ও সিএসভি (UTF-8 BOM) ফাইল এক ক্লিকে রফতানি।

2. **`CashMemoModule.tsx`**:
   - গ্রাহকের জন্য পূর্ণাঙ্গ কম্পিউটার-জেনারেটেড ডিজিটাল ক্যাশ মেমো।
   - পণ্যের দাম, হোম ডেলিভারি ফি, সার্ভিস চার্জ এবং ভেরিফিকেশন কিউআর কোড।
   - ব্রাউজারের প্রিন্ট ডায়ালগ এবং মোবাইল রেসপন্সিভ ফরম্যাট।

3. **`ShopReceiptModule.tsx`**:
   - বিশ্বনাথ বাজারের পার্টনার দোকানদারদের জন্য প্রকিউরমেন্ট ভাউচার।
   - পণ্যের পাইকারি/ক্রয়মূল্য, রাইডারের তথ্য এবং দোকানদারের স্বাক্ষর লাইন।

4. **`LiveDeliveryTracker.tsx`**:
   - বিশ্বনাথ পৌরসভা, লামাকাজী, খাজাঞ্চী, দেওকলস, দৌলতপুর, রামপাশা, অলংকারী, দশঘর এলাকার জন্য বাস্তবসম্মত রুট ও ইটিএ গণনা।
   - মোটরবাইক সিমুলেশন এবং ওয়ান-ট্যাপ রাইডার কল অ্যাকশন।

5. **`ServerApiModule.ts`**:
   - ব্যাকএন্ড এপিআই এন্ডপয়েন্ট ও ডেটা ইন্টারফেসের স্ট্যান্ডার্ড স্পেসিফিকেশন।

### ৩. লোকাল ডেভেলপমেন্ট ও স্টার্টআপ কমান্ড (Commands)
```bash
# ডিপেন্ডেন্সি ইনস্টল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# প্রোডাকশন বিল্ড তৈরি
npm run build

# প্রোডাকশন সার্ভার চালু
npm run start
```
